# Task Spaces Refined

Start with Herdr's desktop workspace layout. Put a collapsible sidebar at the left, the terminal and tab bar in the middle, and the file/changes inspector at the right. Use the supplied theme-independent mods and the layout-scoped shortcuts.

Group the sidebar by host and main checkout, with task roots and assigned linked checkouts. Under each working checkout show native agent sessions once. Show a manager link when a worker has a logical parent. Put Requests next to the file/changes and Automations views. The Task Spaces service talks to a host-local registry rather than deciding ownership from a branch name.

Use the repository's root AGENTS.md and README to install the included layout and matching helpers. On stock Herdr, the installer can add it alongside the shipped layouts. The companion host installer sets up the registry, wrapper and coordination instructions on an already connected machine.
